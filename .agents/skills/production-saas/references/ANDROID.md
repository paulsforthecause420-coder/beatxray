# Android / Play Release Reference

When applicable verify package/application identifier, app name, version/versionCode, icons/splash, necessary permissions, deep links if used, production API, production auth callbacks, billing, signing, release environment, and store disclosure inputs.

Prefer release evidence from a production artifact, successful signing, internal/closed test-track delivery when available, install/update test, login, core workflow, billing/restore if applicable, account switching, and crash/log inspection.

Store-console declarations and account approvals can require human action. Record exact blockers instead of marking them passed.
